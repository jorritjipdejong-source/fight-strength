Fight Strength Week

3 quick gym sessions around your MMA. Tap a day, work top to bottom, tick each set.

The 3 rules
  • Stop every heavy set with about 2 good reps left. Never grind to failure.
  • Move every rep as fast as you can with good form.
  • Add weight next week only if every set felt fast. If a set slowed down, keep the weight.
  • Do all sets of one exercise, then move to the next. Tick a set and the rest timer starts.
  • Short on time: do the warm-up and exercises 1 and 2 only (about 20 min).
  • Flat or sore at MMA: drop one set from every lift that week.
  • Busy gym: the order can change, so start with whatever is free. Just keep the jumps early, while you're fresh. No chalk at Basic-Fit, so bring lifting straps for deadlifts if your grip gives out.
